# Technology Stack

## Backend & Scraping Engine
- **Language**: Python 3.10+
- **Framework**: FastAPI (High-performance async REST API)
- **Scraping Tools**: Playwright / Instaloader / BeautifulSoup4 (Instagram web scraping & data extraction)
- **Data Processing**: Pandas / re (Regex keyword matching & post filtering)

## Frontend Web UI
- **Framework**: Vite + React
- **Styling**: Vanilla CSS with HSL design tokens, Glassmorphism, and Dark Mode
- **HTTP Client**: Axios / Fetch API

## Data Persistence & Export
- **Database**: SQLite / Local JSON Storage
- **Export Formats**: CSV, JSON, Excel
