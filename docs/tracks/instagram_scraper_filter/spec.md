# Track Spec: Instagram Scraper & Keyword Filter Web App

## Goal
Membuat aplikasi web full-stack (FastAPI + React) yang dapat meng-scrape postingan dari Instagram (username/hashtag), memfilter postingan berdasarkan kata kunci yang dicari pada deskripsi/caption, dan menyajikannya dalam antarmuka web modern yang responsif dengan fitur ekspor data.

## Key Deliverables
1. Backend Scraper Engine (Python Playwright/Instaloader + FastAPI REST API).
2. Logic Filter Kata Kunci (exact, partial, multi-keyword AND/OR).
3. Dashboard Web UI (React + Glassmorphism Dark Mode) untuk input scraping, penyaringan postingan, dan tampilan feed.
4. Fitur Ekspor Data (CSV/JSON).
