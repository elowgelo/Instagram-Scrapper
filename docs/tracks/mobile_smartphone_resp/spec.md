# Track Spec: Mobile & Smartphone Responsiveness Optimization

## Goal
Mengoptimalkan seluruh tata letak (layout), navigasi, form, grid kartu, dan tabel aplikasi agar 100% responsif, nyaman, dan presisi saat diakses melalui smartphone (HP) & tablet.

## Scope & Requirements
1. **Responsive Navbar & Layout Container**:
   - Menyesuaikan padding, ukuran font judul, dan letak tombol navigasi agar tidak terpotong pada layar HP (< 640px).
2. **Mobile Stats Grid (2x2 Grid)**:
   - Mengubah grid ringkasan statistik agar secara otomatis menjadi susunan 2x2 rapi pada layar kecil.
3. **Responsive Scrape Form & Keyword Filter Bar**:
   - Mengubah form input, dropdown pilihan, dan tombol aksi menjadi full-width (100%) pada tampilan mobile agar mudah disentuh.
4. **Mobile Feed Grid & Responsive Table**:
   - Mengubah susunan feed kartu menjadi 1 kolom penuh pada smartphone.
   - Memastikan tabel hasil filter memiliki fitur scroll horizontal yang mulus tanpa merusak layout utama.
